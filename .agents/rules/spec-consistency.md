# Specification consistency

- Maintain the document order: PRD, requirements, design, tasks, implementation.
- Every functional requirement must link to a goal or journey and have measurable acceptance criteria.
- Design decisions must trace to requirements; tasks must trace to requirements and acceptance criteria.
- Stop when design contradicts requirements or an acceptance criterion is missing, ambiguous, or unverifiable.
- Create files in `docs/` only when `specs/design.md` links to them.
