# Evidence and scope

- Do not invent users, entities, business rules, constraints, requirements, acceptance criteria, architecture, or technology choices.
- Label repository observations, user decisions, and agent inferences distinctly.
- Record unsupported or ambiguous points as open questions.
- Implement only behavior linked to an approved requirement and acceptance criterion.
- Reject scope expansion hidden inside refactors, cleanup, dependencies, or convenience features unless the user approves it.
