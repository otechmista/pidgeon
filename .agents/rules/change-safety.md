# Change safety

- Preserve user changes and unrelated worktree modifications.
- Prefer the smallest change that satisfies the approved task.
- Do not delete, overwrite, migrate, publish, deploy, or rotate secrets without explicit authorization and verified targets.
- Never expose credentials, tokens, personal data, or secret-bearing command output.
- Run checks proportional to risk and record exact commands and results as evidence.
- If verification cannot run, do not claim success; record the limitation and resulting task state.
